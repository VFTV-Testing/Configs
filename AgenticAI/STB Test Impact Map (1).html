    How this map was built
    • Every scenario in CT/, Sanity/, SanityRetry/ and LongPlayback/ was read in full, including the helper and screen methods it calls where their names do not say what they check. The direct helper calls were then extracted from the code automatically and cross-checked against those tags; entries marked auto came from that cross-check.
    • Checks a shared helper always runs are counted on every test case that uses it: device-ready always validates device metadata, and every tune reads the channel number and checks the Live badge.
    • PIN entry (PIN-03) counts only where a test case targets locked content on purpose. Opportunistic PIN entry when a prompt happens to appear is described in that feature's note instead.
    • Third-party app player controls count as app trickmode (TM-09), not as the native Pause / Rewind / FF checks.
    • Platform is what the scenario code enforces. STB+STV means there is no platform gate in the scenario; some of these are only scheduled on STB today.
    • LongPlayback_Suite dispatches the other LongPlayback scenarios, so it carries the union of their features.
    • Out of scope: Zapping/, Utility/, In_Progress/, the deprecated tests/ folder and _deprecated/. The same data is in Vodafone/docs/TC_Feature_Impact_Analysis.xlsx.
